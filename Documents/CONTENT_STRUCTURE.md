# Project Overview

A premium personal portfolio website for Abdallah Shahbour.

The website presents Abdallah as a Visual Designer focused on:

- Visual Identity
- Brand Design
- Social Media Design
- Creative Visual Experiences

The main goal is to showcase work, experience, and creative capability.

# 5. Selected Work Gallery

## Purpose:

Display design work visually.

This is the main portfolio section.

---

## Layout:

Masonry Gallery.

Desktop:

2 columns.

Mobile:

1 column.


Images should maintain their original aspect ratio.

No artificial cropping.

No empty spaces between different image heights.


---

## Interaction:

Clicking any project image opens a modal.

Modal:

Background:

- Blur effect
- Overlay
- Disable page scrolling


Content:

Large project image.

Information panel:

- Project Name
- Organization / Client
- Category
- Year
- Tools
- Short Description


Social links:

Display only available platforms.

Supported:

- Instagram
- Facebook
- LinkedIn
- TikTok
- Behance
- Dribbble
- Website

Each link uses official platform icon.
