# Abdallah Shahbour Portfolio
## Design Direction Document

---

# Core Identity

The website should feel like a premium creative studio portfolio.

It represents Abdallah Shahbour as:

Visual Designer crafting meaningful visual identities and brand experiences.

The website should prioritize:

- Visual impact
- Creativity
- Premium presentation
- Strong typography
- Motion and interaction

The artwork is the hero.

---

# Overall Style

Direction:

Creative Studio / Editorial / Premium Portfolio

The website should feel:

- Artistic
- Modern
- Experimental
- Elegant
- Interactive
- High-end

Avoid:

- Generic portfolio templates
- Corporate layouts
- Resume-style websites
- Overly simple designs

---

# Theme

## Primary Theme

Light Mode First.

The main experience should use:

- Warm white backgrounds
- Dark typography
- Gold accents
- Soft gradients


Example:

Background:
Warm Off White

Text:
Deep Black

Accent:
Luxury Gold

---

## Dark Mode

Optional.

If implemented:

The dark theme should feel premium, not just inverted colors.

Direction:

- Deep black background
- Gold highlights
- Glass effects
- Cinematic atmosphere

---

# Visual Language

## Layout

Use:

- Editorial layouts
- Large typography
- Strong whitespace
- Asymmetrical compositions
- Large visual elements

Avoid:

Traditional card-heavy layouts.

---

# Hero Direction

The hero should include a personal image.

The image should not look like a normal profile picture.

It should feel like a creative portrait.

Possible approaches:

1. Large editorial portrait
2. Cutout portrait with abstract elements
3. Artistic composition with typography around the image


The goal:

Make the visitor immediately understand:

Who Abdallah is
What he creates
What style he represents

---

# Motion Direction

Motion is a core part of the experience.

The website should feel alive.

---

## Background Motion

Possible elements:

- Floating abstract shapes
- Soft gradients
- Moving light effects
- Grain texture
- Subtle particles
- 3D-inspired elements


Motion should be:

- Smooth
- Premium
- Non-distracting

---

# Typography

Typography should be a major design element.

Use:

- Large display headings
- Elegant fonts
- Strong hierarchy

Need:

Display Font:
For titles

Body Font:
For readability

---

# Selected Work Gallery

Direction:

Masonry Gallery.

Requirements:

- Two columns desktop
- One column mobile
- Original image ratios preserved
- No empty spaces


Interaction:

Click image:

Open fullscreen modal.

Modal:

- Blurred background
- Large artwork preview
- Project information
- Social links

---

Each card contains:

- Cover image

- Description
- Optional Case Study button
